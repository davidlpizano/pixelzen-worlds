CENTRO DE INSTALACIÓN

Instala PixelZen Worlds en segundos

Instalador limpio sin archivos .exe: instala en %LOCALAPPDATA%\PixelZenWorlds, añade accesos directos en Escritorio/Menú Inicio y registra desinstalación estándar.

Instalación rápida para Windows 10 / 11

Descarga e inicia el asistente automático (compatible con Smart App Control y Lively Wallpaper, con motor nativo C# incluido) o ejecuta una sola línea en PowerShell.

⬇ Descargar Instalador (.bat) ⬇ Script PowerShell (.ps1)
✓ Incluye los 15 mundos (45 escenas), estudio de configuración en bandeja, clima dinámico y las 9 tarjetas HUD flotantes.

Generador de comando personalizado

python windows/pixelzen_win.py --tema fittoa --90m --monitores 2
# Abre PowerShell y pega este comando (no requiere Git ni archivos .exe):
irm https://raw.githubusercontent.com/davidlpizano/pixelzen-worlds/main/scripts/instalar.ps1 | iex

# Para instalar activando el arranque automático con Windows:
$s = irm https://raw.githubusercontent.com/davidlpizano/pixelzen-worlds/main/scripts/instalar.ps1
& ([scriptblock]::Create($s)) -AutoInicio
# Estudio gráfico completo (Estudio WPF + Motor C# GDI+ + HUD 9 tarjetas):
powershell -ExecutionPolicy Bypass -File windows\PixelZenMenu.ps1

# Solo aplicar fondo y salir a bandeja:
powershell -ExecutionPolicy Bypass -File windows\PixelZenMenu.ps1 -SoloAplicar

# O desde Python standalone:
python windows/pixelzen_win.py --listar
python windows/pixelzen_win.py --tema solo-leveling --90m
